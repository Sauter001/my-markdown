# MyMD 기능 명세

간이 마크다운 에디터 MyMD의 기능 명세. 현재 구현된 동작을 사용자 관점과 기술 구조로 정리한다.

- 최종 갱신: 2026-06-21
- 대상 플랫폼: Windows 10/11 (x64)
- 형태: 네이티브 단일 실행 파일(`MyMD.exe`) + 로컬 web 자산

## 1. 개요와 목표

- 메모장처럼 즉시 로딩되어 편집 가능한 미니멀 마크다운 에디터.
- 좌측 편집, 우측 렌더링을 병치하고 보기 모드를 자유롭게 전환.
- LaTeX 수식, `<details>` 토글, 이미지, 표 등 일반 마크다운 문법 지원.
- 파일을 열지 않아도 편집 가능하며, 저장은 네이티브 입출력으로 처리.

## 2. 아키텍처

- 네이티브 호스트가 프레임리스 창과 UI를 소유한다. 좌측은 RichEdit 컨트롤(평문 모드 에디터), 우측 패널에만 WebView2를 지연 임베드해 미리보기를 렌더링한다. 에디터 전용 보기에서는 WebView2를 아예
  만들지 않아 메모장급으로 즉시 로딩된다(RichEdit 로드 비용은 미미).
- 코드는 책임별 모듈로 분리되어 있다(`src/main.cpp`는 진입점 only): `App`(조립/메인 윈도우 프로시저/콜백 배선), `core/`(인코딩, JSON, 파일 입출력, 마크다운 순수 로직,
  DPI, RAII), `model/`(Settings, Theme, Keymap), `ui/`(Editor, TableEditor, Topbar, Preview, dialogs/*).
- C++ 호스트가 담당: 창 생성/제어, 상단바, 에디터(RichEdit) 입력 동작(Tab 들여쓰기, 리스트 이어쓰기, 표 편집, 자동 페어링, 라인 편집), 네이티브 파일 대화상자/입출력, 설정 영속화, 표 삽입/설정/단축키 대화상자.
- 미리보기는 `web/preview.html` + `web/preview.js`를 `file://`로 로딩한다. 호스트 -> 미리보기 통신은 `eval(...)`로 `window.mymd*` 함수를 호출하고, 동적
  문자열(본문, 경로 등)은 인코딩 문제를 피하려고 base64로 전달한다. 미리보기 -> 호스트는 외부 링크 열기(`mymdOpenExternal`), 준비 통지(`mymdPreviewReady`), 단축키
  통지(`mymdAccel`)를 `bind` 한다.
- 렌더링은 markdown-it + KaTeX(오프라인 폰트 포함)로 처리하고, 코드 블록 강조는 Prism으로 후처리한다.
- 구 all-in-WebView UI(`web/legacy/index.html`, `web/legacy/app.js`)는 더 이상 로드되지 않으며 참고용으로만 보존한다.

## 3. 에디터

- RichEdit 컨트롤(평문 모드, `TM_PLAINTEXT`) 기반으로 즉시 로딩을 우선한다(입력 영역 자체에는 구문 강조가 없고, 강조는 미리보기 코드 블록에서 처리한다).
- 다단계 실행 취소/다시 실행: Ctrl+Z(취소) / Ctrl+Y(다시 실행). RichEdit 의 다단계 undo 스택을 사용한다(파일 로드는 undo 에 남기지 않음).
- 기본 편집 키(에디터 고정, 재바인딩 대상 아님): 전체 선택(Ctrl+A), 잘라내기/복사/붙여넣기(Ctrl+X/C/V). 선택이 없을 때 Ctrl+X 는 현재 라인 잘라내기, Ctrl+C 는 현재 라인 복사(둘 다 줄바꿈 포함), Ctrl+Del 은 현재 라인 삭제(선택이 여러 줄이면 걸친 라인 전체).
- 글꼴: 고정폭(모노스페이스, Consolas), 크기는 pt 단위로 설정(기본 10pt). 실제 픽셀은 창 DPI와 줌(%)을 반영해 계산하므로 고배율 모니터에서도 일관된 크기로 보인다.
- Tab 키: 표 밖에서는 설정된 칸 수만큼 공백 삽입.
- 리스트 자동 이어쓰기: `-`/`*`/`+`, 번호 목록(`1.`/`1)`), 작업 목록(`- [ ]`) 항목에서 Enter 시 같은 마커를 다음 줄에 이어준다(번호는 1 증가, 작업 목록은 빈 체크박스).
  내용이 없는 빈 항목에서 한 번 더 Enter 시 마커를 제거하여 리스트를 종료한다.
- 자동 줄바꿈(wrap): 기본 켜짐. 편집 칸 너비에 맞춰 접히며, 병치 모드로 편집 칸이 좁아진 경우에도 그 너비에 맞춰 접힌다. 공백 없는 긴 토큰(URL 등)도 접혀 가로로 넘치지 않는다.
    - 설정에서 끄면 줄바꿈 없이 가로 스크롤로 동작한다(코드 등 긴 줄 보기용).
- 입력 시 디바운스(약 110ms) 후 미리보기를 갱신한다.

## 4. 미리보기 렌더링

- 마크다운 기본 문법, 표, 취소선, 인용, 코드 블록.
- 코드 블록 구문 강조: Prism을 지연 로드하여 렌더 후 후처리로 강조한다. 타이핑 경로와 분리된 idle 디바운스(약 200ms)로 처리해 입력 반응성을 유지한다. 강조 대상 언어는 설정의
  `highlightLanguages`로 지정하며, 테마 색상은 라이트/다크에 연동된다.
- 작업 목록(`- [ ]`, `- [x]`)을 체크박스로 렌더링(가벼운 후처리).
- 링크: 미리보기의 외부 링크(`http`/`https`/`mailto`)는 클릭 시 앱 내부에서 탐색하지 않고 C++ 브리지(`mymdOpenExternal` -> `ShellExecuteW`)를 통해 기본
  브라우저로 연다. 문서 내 앵커(`#...`)는 미리보기 안에서 스크롤한다.
- LaTeX 수식: 인라인 `$...$`, 블록 `$$...$$` (KaTeX).
- `<details>`/`<summary>` 등 원시 HTML 허용(`html: true`).
- 이미지: data URI(SVG 포함), 원격 URL, 로컬 상대경로 지원.
    - 링크 검증을 모두 허용으로 두어 `data:image/svg+xml`, `file:` 등도 렌더링된다.
    - 상대경로 이미지는 현재 문서가 있는 폴더 기준 `file://`로 해석한다.
- 긴 텍스트/토큰은 미리보기 폭에 맞춰 접혀 창을 넘지 않는다. 단, 코드 블록(`pre`)은 기존대로 가로 스크롤을 유지한다.
- 라이트/다크 테마(시스템 연동 포함).

## 5. 보기 모드

- 세 가지: 에디터만 / 병치 / 미리보기만.
- 전환: 상단바 아이콘 버튼 또는 단축키(Ctrl+1 / Ctrl+2 / Ctrl+3), 순환(Ctrl+\).
- 기본 보기 모드는 설정에서 지정 가능(기본값 병치).
- 병치 모드에서 에디터 스크롤에 맞춰 미리보기를 비례 동기화(설정 on/off).

## 6. 파일 작업

- 새 파일, 열기, 저장, 다른 이름으로 저장. 모두 네이티브 대화상자 사용.
- Ctrl+S로 현재 파일에 저장. 제목 없는 새 문서면 저장 위치를 묻는다(다른 이름으로 저장).
- 인코딩: 읽을 때 UTF-8 BOM을 제거, 쓸 때 BOM 없이 UTF-8로 기록.
- 실행 인자로 파일 경로를 주면 그 파일을 열고 시작한다(`MyMD.exe "path.md"`).
- 수정 상태(dirty)를 추적하여 제목과 작업표시줄에 표시(앞에 `*`).
- 새 파일/열기 시 미저장 변경이 있으면 확인 후 진행.
- VSCode로 열기(상단바 `VSCode` 버튼 / Ctrl+Shift+V): 현재 문서를 먼저 저장(제목 없으면 다른 이름으로 저장)한 뒤 VSCode로 연다. 설치 경로의 `Code.exe`(
  `%LOCALAPPDATA%\Programs\Microsoft VS Code` 등)를 우선 찾고, 없으면 PATH의 `code`로 폴백한다. 찾지 못하면 안내 메시지를 표시한다.

## 7. 창 (프레임리스)

- OS 기본 타이틀바를 제거한 프레임리스 창(노션 스타일).
- 인앱 상단바에 현재 파일명을 표시(미저장 시 점 표시).
- 이동: 상단바의 빈 영역을 드래그. 더블클릭으로 최대화/복원.
- 크기 조절: 창 가장자리/모서리(약 6px)에서 네이티브 리사이즈. 최대화 시 작업표시줄을 덮지 않도록 보정.
- 최소 크기 480x320, 초기 크기 1120x740(논리 픽셀, DPI 스케일됨).
- 우측 상단에 최소화/최대화(복원)/닫기 버튼.
- 작업표시줄/Alt+Tab 제목은 파일명(미저장 시 `*` 접두), 응용 프로그램 아이콘(favicon) 임베드.
- DPI 인식: 시작 시 Per-Monitor V2 DPI awareness 를 활성화한다. 상단바/버튼/디바이더/대화상자/창 크기 등 모든 픽셀 좌표와 글꼴은 창 DPI 로 스케일하며, `WM_DPICHANGED`(모니터 간 이동)에서 재배치 + 글꼴 재생성한다. 고배율 모니터에서도 선명하고 일관된 크기로 보인다.

## 8. 자동 페어링

- 괄호/따옴표/백틱/별표를 입력하면 짝을 자동으로 맞춘다. 설정 `autoPair`(기본 켜짐)로 끌 수 있다.
- 여는 괄호 `(`, `[`, `{`: 짝을 삽입하고 캐럿을 안쪽에 둔다. 텍스트를 선택한 상태에서 입력하면 선택을 감싸고 안쪽 텍스트를 다시 선택한다.
- 닫는 괄호 `)`, `]`, `}`: 캐럿 바로 뒤가 같은 닫는 문자면 새로 넣지 않고 그 위로 건너뛴다(스킵 오버). 아니면 그대로 입력.
- 따옴표 `"`, `'`: 짝을 삽입하되 캐럿 바로 뒤가 같은 따옴표면 스킵 오버한다. 캐럿 바로 앞이 영문/숫자/`_`/한글이면(축약형 등) 짝을 만들지 않고 그대로 입력한다.
- 백틱 `` ` ``: 처음 누르면 인라인 코드 짝이 만들어진다(`` `|` ``, `|`는 캐럿). 그 빈 짝 사이에서 한 번 더 누르면 펜스드 코드 블록으로 확장한다. 이때 개행(빈 내용 줄)을 넣지 않고 캐럿을 여는 펜스 끝에 둬 언어 식별자(예: `python`)를 곧바로 입력할 수 있게 한다. 인라인 코드를 닫을 때처럼 바로 뒤가 백틱이면 스킵 오버한다.
- 별표 `*`: 짝(`*|*`)을 만들고, 그 사이에서 한 번 더 누르면 굵게(`**|**`)로 확장한다.
- 빈 짝 사이에서 Backspace 를 누르면 양쪽 문자를 함께 지운다.
- 모든 동작은 EDIT 의 한 번의 편집으로 처리해 Ctrl+Z 한 번으로 되돌릴 수 있다. 코드 블록 내부 여부 등 문맥은 구분하지 않는다.

## 9. 표 편의 기능 (에디터)

- 표 인식 기준: 한 줄이 `|`로 시작하거나 `|`를 2개 이상 포함.
- 표 삽입:
    - Ctrl+T: 기본 2열 표 골격(헤더 + 구분선 + 본문 행)을 즉시 삽입하고 첫 헤더 셀을 선택.
    - 상단바 `표` 버튼: 열/행 수를 지정하는 대화상자로 삽입.
- 표 정렬/포맷: Ctrl+Shift+F 또는 상단바 `정렬` 버튼.
    - 커서가 속한 표의 셀 너비를 맞춰 정렬(한글 전각 폭 반영).
    - 정렬 방향(`:--`, `--:`, `:-:`)을 유지하고 구분선이 없으면 자동 생성.
- 셀 이동:
    - Tab: 오른쪽 셀로 이동(셀 내용 선택).
    - 마지막 열에서 Tab: 행으로 넘어가지 않고 열을 추가한 뒤 새 셀로 이동(연속 Tab으로 계속 확장). 헤더/구분선/본문에 함께 추가되고 구분선이 있으면 정렬.
    - Shift+Tab: 왼쪽 셀로, 첫 셀에서는 이전 행의 마지막 셀로.
- 행 추가:
    - 표 행에서 Enter: 같은 열 수의 빈 행을 추가.
    - 헤더만 있고 구분선이 없으면 구분선 + 빈 행을 자동 생성.

## 10. 종료 시 저장 확인

- 미저장 변경이 있는 상태에서 닫기를 시도하면(닫기 버튼 또는 Alt+F4) 확인 모달을 띄운다.
- 선택지: 저장 / 저장 안 함 / 취소(Esc).
    - 저장: 저장 후 종료. 제목 없는 새 문서면 저장 위치를 묻고, 거기서 취소하면 종료하지 않는다.
    - 저장 안 함: 저장하지 않고 종료.
    - 취소: 종료하지 않고 편집으로 복귀.
- 변경이 없으면 확인 없이 즉시 종료.
- 구현: 네이티브가 `WM_CLOSE`를 가로채 미저장이면 네이티브 메시지 박스(`MessageBoxW`, 예/아니오/취소)를 띄운다. "예"는 저장(실패/취소 시 닫지 않음), "아니오"는 저장 없이 종료, "취소"는 편집 복귀.

## 11. 설정

- 저장 위치: 실행 파일 옆 `settings.json`(평면 JSON으로 영속화, BOM 없는 UTF-8).
- 항목과 기본값:
    - `defaultView`: `editor` / `split` / `preview` (기본 `split`)
    - `theme`: `system` / `light` / `dark` (기본 `system`)
    - `fontSize`: 정수 pt (기본 10, 범위 6-40). 실제 픽셀은 DPI/줌 반영해 계산
    - `tabSize`: 정수 칸 (기본 4)
    - `wrap`: 자동 줄바꿈 (기본 true)
    - `scrollSync`: 스크롤 동기화 (기본 true)
    - `autoPair`: 괄호/따옴표/백틱/별표 자동 페어링 (기본 true)
    - `highlightLanguages`: 코드 강조 대상 언어 배열 (기본 `bash`, `c`, `cpp`, `java`, `python`, `html`, `css`, `javascript`, `sql`,
      `json`)
    - `zoom`: 글자 배율(%) (기본 100, 범위 50-300). Ctrl +/- 로 조절, 에디터/미리보기 공통
    - `keymap`: 동작별 단축키 오버라이드 객체(`{id: spec}`). 기본은 빈 객체이며 기본 단축키를 사용. 예: `{"save":"Ctrl+E"}`
- 네이티브 설정 대화상자(상단바 `설정` 버튼 / Ctrl+,)에서 `defaultView`, `theme`, `fontSize`, `tabSize`, `wrap`, `scrollSync`, `autoPair`,
  `highlightLanguages`(활성 언어 목록 + 추가/제거), 단축키(`단축키...` 버튼 -> 키 캡처 대화상자)를 바꾼다. 저장 시 런타임 반영: 글꼴/탭폭 즉시, 테마는 에디터 색(`EM_SETBKGNDCOLOR`/`EM_SETCHARFORMAT`) + 창 브러시 갱신 + 미리보기 통지, `wrap`은 컨트롤
  스타일이 생성 시 고정이라 컨트롤을 재생성(본문/선택 보존), 강조 언어는 미리보기에 통지, 단축키는 ACCEL 재생성 + 미리보기 통지.

## 12. 단축키

아래는 기본값이다. 설정 대화상자의 `단축키...` 버튼으로 동작별 키를 재바인딩할 수 있고(오버라이드는 `settings.json`의 `keymap`에 저장), 줌 보조키(넘버패드 +/-/0)는 고정이다.

| 동작         | 키               | id           |
|------------|-----------------|--------------|
| 저장         | Ctrl+S          | save         |
| 다른 이름으로 저장 | Ctrl+Shift+S    | saveAs       |
| 열기         | Ctrl+O          | open         |
| 새 파일       | Ctrl+N          | new          |
| VSCode로 열기 | Ctrl+Shift+V    | openInVSCode |
| 에디터만 보기    | Ctrl+1          | viewEditor   |
| 병치 보기      | Ctrl+2          | viewSplit    |
| 미리보기만 보기   | Ctrl+3          | viewPreview  |
| 보기 순환      | Ctrl+\          | cycleView    |
| 표 삽입       | Ctrl+T          | insertTable  |
| 표 정렬       | Ctrl+Shift+F    | formatTable  |
| 설정 열기      | Ctrl+,          | settings     |
| 확대         | Ctrl++ / Ctrl+= | zoomIn       |
| 축소         | Ctrl+-          | zoomOut      |
| 배율 초기화     | Ctrl+0          | zoomReset    |

위 표 외에 에디터 고정 편집 키(전체 선택 Ctrl+A, 실행 취소/다시 실행 Ctrl+Z/Ctrl+Y, 라인 잘라내기/복사 Ctrl+X/Ctrl+C(선택 없을 때), 라인 삭제 Ctrl+Del)가 있으며, 이는 재바인딩 대상이 아니라 에디터가 직접 처리한다.

단축키는 두 경로로 동작하며, 둘 다 같은 keymap(기본값 + 사용자 오버라이드)을 따른다. 에디터(RichEdit)에 포커스가 있으면 keymap 으로 만든 Win32 액셀러레이터 테이블(`TranslateAccelerator`)이 처리한다. 미리보기(WebView2)에 포커스가 있으면 ACCEL
이 키를 받지 못하므로, 호스트가 keymap 을 `mymdSetKeymap` 으로 보내고 `preview.js` 가 `keydown` 에서 매칭되는 조합을 가로채(`preventDefault`) 브리지(`mymdAccel`)로 id 를 호스트에 전달하면 호스트가 같은
명령으로 디스패치한다(브라우저 기본 동작인 Ctrl+S 저장 대화 등도 함께 차단). 재바인딩하면 양쪽 경로가 함께 갱신된다. 표 편집(`insertTable`/`formatTable`)은 에디터 전용이라 미리보기 경로에서는 전달하지 않는다.

## 13. 호스트 - 미리보기 브리지 API

파일 입출력, 창 제어, 대화상자, 설정 등은 모두 네이티브에서 처리한다. WebView2 는 미리보기 렌더링 전용이며, 호스트와 미리보기 사이만 아래 API로 통신한다. 동적 문자열 인자는 base64(UTF-8)
로 인코딩한다.

호스트 -> 미리보기 (`g_webview->eval`로 `window.mymd*` 호출):

| 함수                              | 설명                            |
|---------------------------------|-------------------------------|
| `mymdRender(b64)`               | 본문(마크다운)을 렌더링                 |
| `mymdSetTheme("light"\|"dark")` | 미리보기 테마 전환                    |
| `mymdSetBase(b64)`              | 상대경로 이미지 기준 `file://` base 설정 |
| `mymdSetLangs(b64)`             | 코드 강조 대상 언어 배열(JSON) 통지       |
| `mymdSetKeymap(b64)`            | 단축키 매핑(JSON) 통지(미리보기 포커스 단축키) |
| `mymdSetZoom(percent)`          | 글자 배율(%) 적용                    |
| `mymdScrollTo(ratio)`           | 스크롤 비율(0~1)에 맞춰 미리보기 스크롤      |

미리보기 -> 호스트 (`bind`):

| 함수                      | 설명                                              |
|-------------------------|-------------------------------------------------|
| `mymdPreviewReady()`    | 미리보기 준비 완료 통지(이후 호스트가 설정/본문 푸시)                 |
| `mymdOpenExternal(b64)` | 외부 링크를 기본 브라우저로 연다(`http`/`https`/`mailto`만 허용) |
| `mymdAccel(id)`         | 미리보기 포커스에서 가로챈 단축키 동작 id 를 호스트에 전달          |

## 14. OS 통합 (install.ps1)

관리자 권한 없이 사용자 범위로 등록한다(`install.ps1`, 해제는 `uninstall.ps1`).

- 명령 실행: App Paths 등록(Win+R, 시작 검색에서 `mymd`), 사용자 PATH 추가(터미널에서 `mymd`), 시작 메뉴 바로가기.
- 파일 연결: `.md` / `.markdown`에 ProgID(`MyMD.markdown`)와 "연결 프로그램" 등록(Applications, OpenWithProgids).
- Windows 10/11은 보안상 기본 연결을 프로그램이 강제로 바꿀 수 없어, 기본값은 사용자가 "연결 프로그램 > 항상"으로 한 번 지정해야 한다.
- 주의: `MyMD.exe`는 실행 시 옆 `web/` 폴더를 사용하므로 위치를 옮기지 않는다.

## 15. 빌드

- 툴체인: MinGW-w64 g++(동봉 `third_party/mingw64`), 정적 링크 standalone exe.
- 의존: webview 0.10.0 단일 헤더(내장 로더라 `WebView2Loader.dll` 링크 불필요), WebView2 SDK 헤더, web 자산(markdown-it, KaTeX, Prism).
- 아이콘: `src/resource.rc`(favicon.ico)를 windres로 컴파일해 임베드.
- 스크립트: `build.bat`(빌드), `run.bat`(실행). 실행에는 시스템 WebView2 런타임 필요(Windows 10/11 기본 포함).

## 16. 알려진 한계 / 향후

- 미리보기 코드 블록은 Prism으로 강조하지만, 입력 영역(에디터)은 RichEdit 평문 모드라 강조가 없다(즉시 로딩 우선).
- 표 인식은 행 단위 휴리스틱이라 본문 중 우연한 `|`에 반응할 수 있다.
- 별표(`*`) 자동 페어링은 글머리표(`* 항목`)를 입력할 때도 짝을 만든다. 거슬리면 설정에서 자동 페어링을 끄면 된다.
- 로컬 이미지가 특정 경로에서 막히면 호스트에서 data URI로 읽어 보강하는 방안 가능.
- 인쇄/찾기 등은 WebView2 기본 동작에 의존.
- MSVC 빌드 스크립트는 미포함(요청 시 추가 가능).
