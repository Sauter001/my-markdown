# MyMD 기능 명세

간이 마크다운 에디터 MyMD의 기능 명세. 현재 구현된 동작을 사용자 관점과 기술 구조로 정리한다.

- 최종 갱신: 2026-06-19
- 대상 플랫폼: Windows 10/11 (x64)
- 형태: 네이티브 단일 실행 파일(`MyMD.exe`) + 로컬 web 자산

## 1. 개요와 목표
- 메모장처럼 즉시 로딩되어 편집 가능한 미니멀 마크다운 에디터.
- 좌측 편집, 우측 렌더링을 병치하고 보기 모드를 자유롭게 전환.
- LaTeX 수식, `<details>` 토글, 이미지, 표 등 일반 마크다운 문법 지원.
- 파일을 열지 않아도 편집 가능하며, 저장은 네이티브 입출력으로 처리.

## 2. 아키텍처
- UI 전체는 WebView2 안의 로컬 HTML/JS(`web/`)이며 `file://`로 로딩된다.
- C++ 호스트(`src/main.cpp`)는 다음만 담당한다: 창 생성, 네이티브 파일 대화상자/입출력, 창 제목, 설정 영속화, 창 제어.
- JS와 C++는 `webview.bind` 브리지로 통신한다. 인코딩 문제를 피하려고 모든 동적 문자열(내용, 경로, 파일명, 설정)을 base64로 주고받는다.
- 렌더링은 markdown-it + KaTeX(오프라인 폰트 포함)로 처리한다.

## 3. 에디터
- 단순 textarea 기반(구문 강조 없음)으로 즉시 로딩을 우선한다.
- 글꼴: 고정폭(모노스페이스), 크기 설정 가능.
- Tab 키: 표 밖에서는 설정된 칸 수만큼 공백 삽입.
- 자동 줄바꿈 on/off 설정 가능.
- 입력 시 디바운스(약 110ms) 후 미리보기를 갱신한다.

## 4. 미리보기 렌더링
- 마크다운 기본 문법, 표, 취소선, 인용, 코드 블록.
- 작업 목록(`- [ ]`, `- [x]`)을 체크박스로 렌더링(가벼운 후처리).
- LaTeX 수식: 인라인 `$...$`, 블록 `$$...$$` (KaTeX).
- `<details>`/`<summary>` 등 원시 HTML 허용(`html: true`).
- 이미지: data URI(SVG 포함), 원격 URL, 로컬 상대경로 지원.
  - 링크 검증을 모두 허용으로 두어 `data:image/svg+xml`, `file:` 등도 렌더링된다.
  - 상대경로 이미지는 현재 문서가 있는 폴더 기준 `file://`로 해석한다.
- 라이트/다크 테마(시스템 연동 포함).

## 5. 보기 모드
- 세 가지: 에디터만 / 병치 / 미리보기만.
- 전환: 상단바 아이콘 버튼 또는 단축키(Ctrl+1 / Ctrl+2 / Ctrl+3), 순환(Ctrl+\).
- 기본 보기 모드는 설정에서 지정 가능(기본값 병치).
- 병치 모드에서 에디터 스크롤에 맞춰 미리보기를 비례 동기화(설정 on/off).

## 6. 파일 작업
- 새 파일, 열기, 저장, 다른 이름으로 저장. 모두 네이티브 대화상자 사용.
- Ctrl+S로 현재 파일에 저장. 제목 없는 새 문서면 저장 위치를 묻는다(다른 이름으로 저장).
- 인코딩: 읽을 때 UTF-8 BOM을 제거, 쓸 때 BOM 없이 UTF-8로 기록.
- 실행 인자로 파일 경로를 주면 그 파일을 열고 시작한다(`MyMD.exe "path.md"`).
- 수정 상태(dirty)를 추적하여 제목과 작업표시줄에 표시(앞에 `*`).
- 새 파일/열기 시 미저장 변경이 있으면 확인 후 진행.

## 7. 창 (프레임리스)
- OS 기본 타이틀바를 제거한 프레임리스 창(노션 스타일).
- 인앱 상단바에 현재 파일명을 표시(미저장 시 점 표시).
- 이동: 상단바의 빈 영역을 드래그. 더블클릭으로 최대화/복원.
- 크기 조절: 창 가장자리/모서리(약 6px)에서 네이티브 리사이즈. 최대화 시 작업표시줄을 덮지 않도록 보정.
- 최소 크기 480x320, 초기 크기 1120x740.
- 우측 상단에 최소화/최대화(복원)/닫기 버튼.
- 작업표시줄/Alt+Tab 제목은 파일명(미저장 시 `*` 접두), 응용 프로그램 아이콘(favicon) 임베드.

## 8. 자동 페어링 (에디터)
- 대상 문자: `(` `[` `{` `"` `'` `` ` `` `*`.
- 여는 문자 입력 시 닫는 짝을 자동 삽입하고 커서를 가운데로 둔다.
- 선택 영역이 있으면 양쪽을 감싼다. 예: `굵게` 선택 후 `*` -> `*굵게*`, 다시 `*` -> `**굵게**`.
- `*|*` 사이에서 `*` 입력 시 `**|**`로 확장(굵게 진입).
- 이미 있는 닫는 문자/대칭 문자 위에서 같은 문자를 누르면 건너뛴다(중복 방지).
- 빈 짝(`()`, `""` 등) 사이에서 Backspace 시 양쪽을 함께 삭제.
- 한글 조합 중에는 동작하지 않으며, 영문/숫자/한글 바로 뒤의 `'`/`"`는 페어링하지 않는다(축약형 대응).
- `execCommand` 사용으로 Undo가 보존된다.

## 9. 표 편의 기능 (에디터)
- 표 인식 기준: 한 줄이 `|`로 시작하거나 `|`를 2개 이상 포함.
- 표 삽입:
  - Ctrl+T: 기본 2열 표 골격(헤더 + 구분선 + 본문 행)을 즉시 삽입하고 첫 헤더 셀을 선택.
  - 상단바 `표` 버튼: 열/행 수를 지정하는 대화상자로 삽입.
- 표 정렬/포맷: Ctrl+Shift+F 또는 상단바 `정렬` 버튼.
  - 커서가 속한 표의 셀 너비를 맞춰 정렬(한글 전각 폭 반영).
  - 정렬 방향(`:--`, `--:`, `:-:`)을 유지하고 구분선이 없으면 자동 생성.
- 셀 이동:
  - Tab: 오른쪽 셀로 이동(셀 내용 선택).
  - 마지막 열에서 Tab: 행으로 넘어가지 않고 열을 추가한 뒤 새 셀로 이동(연속 Tab으로 계속 확장). 헤더/구분선/본문에 함께 추가되고 구분선이 있으면 정렬.
  - Shift+Tab: 왼쪽 셀로, 첫 셀에서는 이전 행의 마지막 셀로.
- 행 추가:
  - 표 행에서 Enter: 같은 열 수의 빈 행을 추가.
  - 헤더만 있고 구분선이 없으면 구분선 + 빈 행을 자동 생성.

## 10. 종료 시 저장 확인
- 미저장 변경이 있는 상태에서 닫기를 시도하면(닫기 버튼 또는 Alt+F4) 확인 모달을 띄운다.
- 선택지: 저장 / 저장 안 함 / 취소(Esc).
  - 저장: 저장 후 종료. 제목 없는 새 문서면 저장 위치를 묻고, 거기서 취소하면 종료하지 않는다.
  - 저장 안 함: 저장하지 않고 종료.
  - 취소: 종료하지 않고 편집으로 복귀.
- 변경이 없으면 확인 없이 즉시 종료.
- 구현: 네이티브가 `WM_CLOSE`를 가로채 미저장이면 닫기를 보류하고 JS 모달을 띄운다. "저장 안 함"은 강제 종료 경로(`mymdForceClose`)로 처리한다.

## 11. 설정
- 저장 위치: 실행 파일 옆 `settings.json`(base64로 영속화).
- 항목과 기본값:
  - `defaultView`: `editor` / `split` / `preview` (기본 `split`)
  - `theme`: `system` / `light` / `dark` (기본 `system`)
  - `fontSize`: 정수 px (기본 14)
  - `tabSize`: 정수 칸 (기본 4)
  - `wrap`: 자동 줄바꿈 (기본 true)
  - `scrollSync`: 스크롤 동기화 (기본 true)
  - `keymap`: 동작별 단축키 문자열
- 설정 모달에서 위 항목과 단축키를 변경하고, 단축키는 키 입력 캡처로 재바인딩한다.

## 12. 기본 단축키
| 동작 | 키 | id |
| --- | --- | --- |
| 저장 | Ctrl+S | save |
| 다른 이름으로 저장 | Ctrl+Shift+S | saveAs |
| 열기 | Ctrl+O | open |
| 새 파일 | Ctrl+N | new |
| 에디터만 보기 | Ctrl+1 | viewEditor |
| 병치 보기 | Ctrl+2 | viewSplit |
| 미리보기만 보기 | Ctrl+3 | viewPreview |
| 보기 순환 | Ctrl+\ | cycleView |
| 표 삽입 | Ctrl+T | insertTable |
| 표 정렬 | Ctrl+Shift+F | formatTable |
| 설정 열기 | Ctrl+, | settings |

전역 단축키 처리는 캡처 단계에서 동작하여 WebView2 기본 동작(예: Ctrl+S 저장 대화)을 가로챈다.

## 13. JS - C++ 브리지 API
모든 문자열 인자/반환값은 base64(UTF-8)로 인코딩한다.

| 함수 | 방향 | 설명 |
| --- | --- | --- |
| `mymdReady()` | JS->C++ | 시작 시 실행 인자 파일이 있으면 내용 반환 |
| `mymdOpen()` | JS->C++ | 열기 대화상자, 내용 반환 |
| `mymdSave(b64)` | JS->C++ | 현재 경로에 저장. 경로 없으면 `needSaveAs` |
| `mymdSaveAs(b64)` | JS->C++ | 저장 위치 지정 후 저장 |
| `mymdNew()` | JS->C++ | 현재 문서 상태 초기화 |
| `mymdSetDirty(bool)` | JS->C++ | 수정 상태 갱신(제목 `*`) |
| `mymdLoadSettings()` / `mymdSaveSettings(b64)` | JS->C++ | 설정 읽기/쓰기 |
| `mymdDragMove()` | JS->C++ | 창 드래그 이동 시작 |
| `mymdMinimize()` / `mymdToggleMax()` / `mymdClose()` | JS->C++ | 창 제어 |
| `mymdForceClose()` | JS->C++ | 저장 확인 우회 강제 종료 |
| `window.mymdOnCloseRequest()` | C++->JS | 미저장 종료 시도 시 호출(확인 모달) |

## 14. OS 통합 (install.ps1)
관리자 권한 없이 사용자 범위로 등록한다(`install.ps1`, 해제는 `uninstall.ps1`).

- 명령 실행: App Paths 등록(Win+R, 시작 검색에서 `mymd`), 사용자 PATH 추가(터미널에서 `mymd`), 시작 메뉴 바로가기.
- 파일 연결: `.md` / `.markdown`에 ProgID(`MyMD.markdown`)와 "연결 프로그램" 등록(Applications, OpenWithProgids).
- Windows 10/11은 보안상 기본 연결을 프로그램이 강제로 바꿀 수 없어, 기본값은 사용자가 "연결 프로그램 > 항상"으로 한 번 지정해야 한다.
- 주의: `MyMD.exe`는 실행 시 옆 `web/` 폴더를 사용하므로 위치를 옮기지 않는다.

## 15. 빌드
- 툴체인: MinGW-w64 g++(동봉 `third_party/mingw64`), 정적 링크 standalone exe.
- 의존: webview 0.10.0 단일 헤더(내장 로더라 `WebView2Loader.dll` 링크 불필요), WebView2 SDK 헤더, web 자산(markdown-it, KaTeX).
- 아이콘: `src/resource.rc`(favicon.ico)를 windres로 컴파일해 임베드.
- 스크립트: `build.bat`(빌드), `run.bat`(실행). 실행에는 시스템 WebView2 런타임 필요(Windows 10/11 기본 포함).

## 16. 알려진 한계 / 향후
- 에디터는 단순 textarea라 구문 강조가 없다(즉시 로딩 우선).
- 표 인식은 행 단위 휴리스틱이라 본문 중 우연한 `|`에 반응할 수 있다.
- 로컬 이미지가 특정 경로에서 막히면 호스트에서 data URI로 읽어 보강하는 방안 가능.
- 인쇄/찾기 등은 WebView2 기본 동작에 의존.
- MSVC 빌드 스크립트는 미포함(요청 시 추가 가능).
